# Quiz Conducción Chile

Una aplicación web sencilla e interactiva para estudiar para el examen de conducción chileno. 

## Características
- Presenta las preguntas de forma aleatoria, asegurando que se repasen todas sin repetirse prematuramente.
- Agrupación por bloques de 12 preguntas para mantener la concentración.
- Estilo visual limpio y moderno (Glassmorphism / Apple-inspired).
- Panel de analítica para ver errores por temas y rachas de aciertos.
- Completamente offline (utiliza LocalStorage para guardar el progreso).

## Uso local
1. Clona el repositorio.
2. Abre `index.html` en cualquier navegador moderno.

## Despliegue
Este proyecto es estático (HTML/CSS/JS) y puede alojarse fácilmente en Vercel, Netlify o GitHub Pages.
